# 雷区搭档

项目 A 的本地浏览器试玩入口。打开 [试玩页](http://127.0.0.1:8091/)，两位玩家各自在一个标签页加入大厅。房主开局后，两边共用同一张棋盘。左键翻格，右键插旗，也可以用棋盘下方的按钮切换操作。

## 重新启动

如果试玩服务已经停止，在仓库根目录运行：

```powershell
pwsh -NoProfile -File .\tools\playtest\start.ps1
```

保持进程运行，再打开试玩页。按 Ctrl+C 停止。端口可用 `-Port` 指定，打开对应的 `127.0.0.1` 地址。

启动脚本把已验证的 A2 提交 `e3413e3` 导出到仓库外，只在临时副本中加入静态页面和本机监听。浏览器通过同一地址的 `/ws` 使用原有二进制协议，翻格、插旗和胜负由 A2 服务判定。试玩使用合作／简单模式。

## 试玩 A3 的单局战绩

启动本机 MySQL 学习实例，并在当前 PowerShell 进程设置 `MINESWEEPER_MYSQL_DSN` 后运行：

```powershell
pwsh -NoProfile -File .\tools\playtest\start.ps1 -Backend A3Detail -Port 8092
```

打开 [A3 试玩页](http://127.0.0.1:8092/)。一局结束后，从服务端日志复制该局编号，打开 [单局战绩](http://127.0.0.1:8092/result.html)，输入编号并点击「查询战绩」。页面通过 `GET /matches/{gameID}` 读取本机 MySQL 中的对局和玩家成绩。

`A3Detail` 使用提交 `8ae3412` 的仓库外临时副本，保留已写好的结算保存和详情查询。启动脚本仅在该副本跳过尚未接线的分页处理函数。A2 试玩可继续使用 8091 端口。

## 试玩 A3 战绩列表

启动本机 MySQL 实例并设置本机学习库连接后运行：

```powershell
pwsh -NoProfile -File .\tools\playtest\start.ps1 -Backend A3 -Port 8093
```

`A3` 使用当前已保存的仓库源码构建，网页和本机监听仍只加到临时副本。打开 [A3 大厅](http://127.0.0.1:8093/)，点「战绩」后在新标签页看列表，点一条记录读单局详情。返回列表会回到原来的页码。
